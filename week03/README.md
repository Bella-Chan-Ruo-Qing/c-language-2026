## 来时路（按时间顺序）

**10-25 · 第一个程序**
`age.c` —— 输入年龄，输出"成年 / 未成年"。人生第一个 `if`。

**10-26 · 凯撒密码**
自己敲出加密循环，`hello` → `khoor`。
然后加解密模块，完成 `hello → khoor → hello` **往返自证**。
第一次知道：解密就是加密的**逆操作**。

**10-27 · 密钥与版本管理**
写死的 `3` 换成用户输入的 `shift` —— 算法公开、密钥保密。
遇到人生第一个**逻辑 bug**：编译器零警告，但密钥没接上（靠"对照预期验证输出"抓到）。
大小写通吃。第一次走通 `git clone → commit → push`。

**10-30 · 维吉尼亚 + 暴力破解**
多表替换：凯撒是维吉尼亚密钥长度为 1 的特例。
晚上写 `crack.c`，把自己造的锁一秒钟撬开——**钥匙空间只有 25，太小了**。

**10-31 · 频率分析破维吉尼亚**
洞察：密钥每 3 个字母循环，所以整段密文 = **3 个凯撒交织**。
17576 种密钥瞬间塌缩成 3 个凯撒。
武器只有一条观察：凯撒只平移、不改频率分布形状，所以密文里最多的字母 ≈ 明文的 `e`。

**10-31 · 实战**
拿到一段**未知密钥**的密文，程序自己吐出 `d` `o` `g`。
用 `vigenere_dec.c` 还原明文：

> *every secret message has a key and once you know the key the secret is no longer hidden from you*

## 这一周摸到的密码学概念

- **模运算 `% 26`** —— 字母表是个环。RSA / 椭圆曲线 / AES 骨子里全在跑它。
- **逆操作** —— 解密 = 加密倒着走。这条适用于所有现代密码。
- **密钥空间** —— 判断算法安不安全的第一个动作：数钥匙有几把。凯撒 25 把（秒破），维吉尼亚 26³ = 17576 把（骗了欧洲 300 年）。
- **频率分析** —— 统计方法，不是魔法。**文本越长越准**。
- **分而治之** —— Kasiski 攻破"不可破译"神话的全部思路。
- **一次一密（one-time pad）** —— 密钥不循环、够长、够随机、永不重用 → 香农证明**无条件安全**。这是古典密码的终点，也是密码学最朴素的真理：**安全不在算法多复杂，而在密钥。**
